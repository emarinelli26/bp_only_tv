# Edge Add-ons listing: TV menu navigation

Upload the CI artifact `tv-menu-extension-store-package.zip` as downloaded (do not unzip it), and `logo-300.png` from `tv-menu-extension-store-listing`.

**Name:** TV menu navigation

**Category:** Accessibility

**Short description:**
Controller navigation for the BigPictureTV TV menu: arrow keys move a focus box between links and buttons, and work video players.

**Description:**
Companion to BigPictureTV, a Windows app that keeps Steam Big Picture and a console-style TV menu on the TV. The TV menu opens sites like Crunchyroll in an app window and turns the controller into arrow keys; this extension makes those keys move a visible focus box between the links and buttons of the page, open the chosen one with Enter, jump to the page's search (F2), and seek or pause video players, also inside embedded players.

It only acts in the app windows the TV menu opens (windows without tabs or an address bar). In normal browser windows it does nothing.

**Privacy:** the extension collects, stores and sends no data. It has no permissions beyond running its scripts on pages, and talks to no server.

**Why it runs on all sites:** the TV menu's tiles can open any site the user adds.
